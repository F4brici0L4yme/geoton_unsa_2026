# Documentación (`docs/`)

Este directorio está reservado para la documentación fundamental y de apoyo del proyecto.

## ¿Qué incluir aquí?
- **Diccionarios de datos**: Documento con la explicación, tipo de dato y origen de cada variable o columna de los datasets.
- **Manuales técnicos y de negocio**: Instrucciones detalladas sobre lógicas de negocio, arquitecturas del proyecto o ejecución de procesos complejos.
- **Notas de diseño**: Decisiones analíticas o de arquitectura, referencias a papers, artículos o bibliografía relevante para sustentar los enfoques.
- **Minutas y planificaciones**: (Opcional) Registro de decisiones tomadas en reuniones, alcance y requerimientos.

Mantener esta documentación actualizada es clave para la longevidad del proyecto y la fácil integración de nuevos colaboradores al equipo.
