# Reportes (`reports/`)

Directorio exclusivo para almacenar los reportes o reportes ejecutivos generados a lo largo del ciclo de vida, investigación y experimentación.

## Contenido Habitual
- **Figuras y Visuales**: Carpeta `figures/` o archivos de imágenes resultantes (`.png`, `.pdf`, `.svg`). Todo gráfico que documenta un análisis crucial se aloja aquí para no perderse en los notebooks.
- **Informes HTML/PDF Automatizados**: Por ejemplo, reportes EDA generados con herramientas como `pandas-profiling`, `sweetviz`, `ydata-profiling`.
- **Informes para el Negocio**: PDF finales editables o presentaciones clave requeridas para visualizar los hallazgos de forma concreta y no-técnica.

Esta sección es puramente orientada al entendimiento externo por partes interesadas (*stakeholders*) y documenta la historia a lo largo del ciclo analítico.
